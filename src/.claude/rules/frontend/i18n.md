# i18n

## Dynamic Keys (Prohibited)

Keys must be static string literals. A key assembled at runtime leaves no way to tell whether a catalog entry is still in use.

```typescript
// Bad
t(`error.${errorCode}`);
t(errorKey);
$localize`:@@${dynamicId}:text`;

// Good
t("error.notFound");
t("error.unauthorized");
$localize`:@@errorNotFound:Not found`;
```

## Standalone Key Declaration (Prohibited)

Write keys inline at the translation call. A key held in a variable or an object property hides its use the same way.

```typescript
// Bad
const key = "common.submit";
t(key);

const keys = { submit: "common.submit" };
t(keys.submit);

// Good
t("common.submit");
```
